## Decision rule

A concern is `implemented` only when a concrete artifact and an automated check exist. It is `pending live evidence` when code exists but no final result pool has been generated. It is `pending human evidence` when the claim requires an independent person rather than author or AI review. The current May 2026 manuscript must not describe any pending item as completed.

## Evidence-preserving execution order

1. Preserve the completed digest-bound scenario QA and obtain expert rubric-content feedback.
2. Run `scripts/preflight_api_models.py` and preserve requested/resolved model IDs.
3. Run the frozen 12-scenario operational pilot. Pilot outcomes are excluded from headline estimates.
4. Apply only prespecified, documented rubric or interface repairs; freeze `configs/analysis_plan_v2.json`, prompts, dataset, model configs, and code commit.
5. Run main target generation, then judge the cached responses. Do not regenerate a target merely to change judges.
6. Run the frozen paraphrase robustness matrix.
7. Execute completeness, failure, same-family, frame-effect, matched-control, and paraphrase audits; freeze the response pool.
8. Export the prespecified blinded sample: 72 expert conversations (54 representative + 18 disagreement-enriched, two ratings each) and 108 student A/B pairs (three ratings each). Report expert sampling strata separately.
9. Replace the legacy manuscript’s methods, results, abstract, and conclusion only from frozen outputs. Preserve the legacy experiment as a labelled baseline rather than mixing its scores with rubric v2.

## Claims that remain prohibited

- “Popular conspiracy theories” without population-level prevalence evidence.
- “Clinically safe,” “deployment safe,” or “causes/avoids user harm.”
- A universal model ranking or broad scaling law from the tested snapshots.
- Human-validated, independently reviewed, or expert-aligned before the human study is complete.
- Prompt-robust before the frozen rephrasing study is complete.
- A v2 result inferred from the legacy 24-scenario experiment.
