# Contemporary conspiracy-motif survey for the primary benchmark

Survey date: 2026-09-01  
Target window: public circulation documented in 2023–2026  
Status: 51 circulation-grounded candidates identified; proposed 30-motif subset is pending user selection

## Decision

The survey currently contains **51 independently documented candidate motifs**. A proposed 30-motif subset is listed below, but it is not final until the user selects it. If 30 are retained, they yield **90 primary scenarios** before framing; if all 51 are retained, they yield **153 primary scenarios**. The five frame families are experimental conditions over those scenarios; they do not increase the number of independent motifs. Paraphrase variants remain nested within frame family and should be run on a later frozen robustness subset.

Do not include the legacy 24 scenarios or topic-matched controls in the primary count. The legacy set is a replication appendix. Controls, if run, are auxiliary discriminant-validity data.

This survey has one eligibility question: **was this same or a very close, complete conspiracy narrative actually discussed in the source window?** It does not determine whether the underlying allegation is true, false, supported, unsupported, or resolvable. The linked sources establish circulation and help reconstruct the narrative faithfully; they do not adjudicate it. The survey also does not establish prevalence or clinical validity.

## Inclusion rule

A motif is eligible for the primary set when both of the following hold:

1. A dated 2023–2026 source shows that the same or a very close narrative circulated publicly.
2. The documented narrative itself contains hidden agency, coordination, intentional manipulation, or concealment; it is not merely an underlying technical risk turned into a conspiracy by the benchmark author.

Distinctness, safe fictionalization, and three-structure portability remain dataset-design checks, but they are not tests of whether a conspiracy narrative is genuinely in circulation.

## Variants not counted as additional candidates

- Hurricane-specific cloud-seeding variants: event variants, not independent mechanisms.
- Multiple food-delivery variants for hidden mRNA vaccination: beef, pork, shrimp, and produce are paraphrase/event variants of one motif.
- Additional FEMA-seizure and smart-city-fire retellings with no new complete plot: event variants nested under documented disaster-land-grab stories.
- Generic “the government is monitoring everything” prompts: too broad to source or fact-check consistently.
- `lab_grown_meat_turbo_cancer`: the cancer allegation and the centralized-food-control allegation each circulated, but the audit did not find one source documenting the benchmark's combined actor/action/goal/mechanism/concealment package. Combining them would create the narrative rather than reproduce it, so it is excluded from the candidate pool.

## Possible size after selection

- Proposed 30: 30 documented motifs × 3 interaction structures = **90 primary scenarios**.
- All circulation-grounded candidates: 51 × 3 = **153 primary scenarios**.
- With five canonical frame families, these become **450** or **765** primary scenario–frame cells per model, respectively.
- Legacy 24 scenarios are reported separately as replication data.
- Controls are optional auxiliary data and are not counted as primary.
- Paraphrase variants are run only on a preregistered frozen subset and are not counted as new motifs or scenarios.

## Current implementation gate

The circulation-record step is now complete for all 51 candidates. Before adding a final selection to the runnable catalog:

1. user selects the final motif IDs from the 51-candidate pool; 30 is a proposed size, not a discovered limit;
2. freeze the chosen IDs and category balance;
3. freeze the narrative elements that must remain the same across the three interaction structures;
4. author single-turn, multi-turn, and non-contingent scripted-resistance versions from the same propositions;
5. run naturalness, severity-balance, duplication, leakage, and structure-coherence audits;
6. then implement the five agreed frame families and run the API pilot.

Human review remains later. It validates the completed rubric and frozen response sample; it is not needed to begin the narrative-record, authoring, code, or API-pilot work above.

The machine-readable candidate boundary is `configs/primary_motif_manifest_v3.json`: 30 proposed primary motifs plus 21 additional eligible candidates. `configs/motif_narratives_v3.json` contains the complete 51-record narrative layer, and its validator enforces exact coverage under the sole `documented_public_discourse_only` content gate. `configs/motif_quality_review_v3.json` separately records fidelity, overlap, and authoring-risk judgments without changing that gate.
